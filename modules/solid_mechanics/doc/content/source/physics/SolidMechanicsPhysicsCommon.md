# Common Syntax for Solid Mechanics

## Description

This action adds the parameters supplied at the `[/Physics/SolidMechanics/QuasiStatic]` or `[/Physics/SolidMechanics/Dynamic]`
level as defaults for all the sub-blocks.

See the description, example use, and parameters on the [SolidMechanics/QuasiStatic](/Physics/SolidMechanics/QuasiStatic/index.md) action system page.

!alert note
It performs the same action on the deprecated `[Modules/TensorMechanics/Master]` and
`[Modules/TensorMechanics/DynamicMaster]` syntaxes.
